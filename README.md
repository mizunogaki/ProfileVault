# WoW Forever Settings Mod - ProfileVault

Мод для сохранения настроек графики и привязки клавиш в WoW Forever.

## Установка

1. Скопируйте файлы в папку Interface/AddOns
2. Перезапустите игру через /reload

## Полезные команды

/pv save [название] - сохраняет профиль.
/pv load [название] - загружает профиль.
Управлять профилями можно тут: Настройки > Модификации > ProfileVault

## Как перенести профили настроек в релиз

Сохранённые профили лежат в файле переменных аддона (SavedVariables). Пример пути:
Warcraft\_classic_beta_\WTF\Account\1403721991#1\SavedVariables\ProfileVault.lua

Профили на **аккаунт** — не привязаны к конкретному персонажу.
Файл перезаписывается **не в момент `/pv save`**, а при выходе из игры, `/reload` или релоге. До этого новый профиль живёт только в памяти.

`.bak` — это предыдущее содержимое файла (авто-бэкап клиента при перезаписи).
- Чтобы перенести профили на другой клиент/аккаунт — достаточно скопировать `ProfileVault.lua` в такую же папку `SavedVariables` целевого клиента.
