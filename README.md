# WoW Forever Settings Mod - ProfileVault

Мод для сохранения настроек графики и привязки клавиш в WoW Forever.

## Установка

1. Скопируйте файлы в папку Interface/AddOns
2. После настроек графики и клавиш сохраните профиль через команду обязательно перезапустите игру через /reload, чтобы профиль записался.  

## Полезные команды

/pv save [название] - сохраняет профиль.

/pv load [название] - загружает записанный ранее профиль.
Управлять профилями можно в тут: Настройки > Модификации > ProfileVault

Гайд по консольным командам для грубоких настроек графики: https://github.com/mizunogaki/ProfileVault/blob/main/COMMANDS_ru.md
