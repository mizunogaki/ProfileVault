# WoW Forever Settings Mod - ProfileVault

Мод для сохранения настроек графики и привязки клавиш в WoW Forever. Создавайте отдельные профили, которые хранят ваши настройки, включая тонкие графические опции, такие как количество растительности и дальности прорисовки объектов ландшафта. 

## Установка

1. Распакуйте файл [ProfileVault.zip](https://github.com/mizunogaki/ProfileVault/releases)
2. Скопируйте папку ProfileVault в папку Interface/AddOns
3. После настроек графики и клавиш сохраните профиль через команду `/pv save [название]` обязательно перезапустите игру через `/reload`, чтобы профиль записался.  

## Полезные команды

/pv save [название] - сохраняет профиль.

/pv load [название] - загружает записанный ранее профиль.
Управлять профилями можно в тут: Настройки > Модификации > ProfileVault

Гайд по консольным командам для глубоких настроек графики — [жмяк](https://github.com/mizunogaki/ProfileVault/blob/main/COMMANDS_ru.md).

## Как перенести настройки профилей из беты в релиз WoW Forever

Сохранённые профили лежат в файле переменных аддона (SavedVariables). 

Пример пути: Warcraft_classic_beta_\WTF\Account\1403721991#1\SavedVariables\ProfileVault.lua

Профили создаются на аккаунт — они не привязаны к конкретному персонажу. 

Важно: файл перезаписывается не в момент `/pv save`, а при выходе из игры, `/reload` (перезагрузка UI) или релоге. До этого новый профиль живёт только в памяти. Чтобы команда `/pv load` могла корректно загрузить профиль, обязательно делайте `/reload` или релог. 

.bak — это предыдущее содержимое файла (авто-бэкап клиента при перезаписи).

Чтобы перенести профили на другой клиент/аккаунт — достаточно скопировать ProfileVault.lua в такую же папку SavedVariables целевого клиента.
